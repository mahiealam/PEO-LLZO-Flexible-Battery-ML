# AI-Guided Multiscale Design of PEO-LLZO Solid-State Batteries
Repository containing the data, machine learning pipelines, and experimental plotting scripts for the manuscript: *"AI-GUIDED MULTISCALE DESIGN AND OPTIMIZATION OF FLEXIBLE PEO-LLZO COMPOSITE SOLID-STATE BATTERIES FOR NEXT-GENERATION MEDICAL AND IOT PLATFORMS"*

## Repository Structure
* **/data:** Contains both raw electrochemical/mechanical lab data and the LHS-expanded ML datasets.
* **/notebooks:** 
  * `Experimental_Data_Plotting.ipynb`: Generates publication-ready figures (Nyquist, Galvanostatic, etc.) directly from raw lab data.
  * `Pipeline.ipynb`: The end-to-end ML workflow (XGBoost/RF/SVR training, 5-Fold CV, Ablation Study, and SHAP analysis).
* **/figures:** High-resolution outputs generated by the notebooks.
* **/models:** The serialized, pre-trained XGBoost model for immediate deployment or testing.

## How to Run
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the Jupyter Notebooks located in the `/notebooks` directory.
